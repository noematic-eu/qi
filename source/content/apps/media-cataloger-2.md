DiskShelf lists your disks in a local catalog. Once a volume is indexed, you browse its tree, search files, and see what uses space — even when the disk is unplugged. Not a DAM, not iTunes, not an EXIF editor: a shelf.

On **macOS**, two apps, one engine: **Swift + nmcd** (native) and **nmcui** (Go / Fyne). On **Windows** and **Linux**, the Go build. One license opens all three.

### Features

#### Local and offline disk structure

Even disconnected, you can view the folder tree, modification dates, and sizes.

#### Instant disk overview

Free space at a glance, including local and remote volumes.

#### Visualize disk space consumption

See which folders and files take up the most space, so you can decide what to keep.

#### File search

By name or extension, across all catalogued drives — connected or not.

#### Catalog disks from anywhere with SSH

Using the Secure Shell protocol, from a remote computer.

#### Duplicate file detection

Copies on the same disk or across several disks.

#### Customizable duplicate lists

By subject, owner, or any criteria you choose.

#### Unique file finder

Files that exist on only one disk.

#### Remove unnecessary duplicates

Free space by taking out redundant copies.

#### Optimized for multi-processors

Indexing walks folders in parallel, so large catalogs stay manageable.

### Frequently Asked Questions {#faq}

#### DiskShelf or Media Cataloger?

**One product.** DiskShelf is the name. Media Cataloger is the public **0.0.1** zip shelf (Mac Intel, Windows, Linux) until a DiskShelf zip exists. You are not buying two apps.

#### I already have a Media Cataloger license (0.2 beta by email)?

Yes. **Licenses already sent** and **any new request** open DiskShelf. Same license file. A March buyer is not left out.

#### Does this cover Windows and Linux, or only the Swift Mac app?

Both. The license is for the **Go build** (nmcui) on Windows, Linux, and Mac — not only the Swift macOS app. Go 0.0.1 zips are still on <a href="/media-cataloger">Media Cataloger</a>.

#### Two Mac apps?

Yes: **Swift + nmcd** (native) and **nmcui** (Go / Fyne). Same engine, same license.

#### Is it open source?

Some parts. DiskShelf is a Noematic desktop app.

#### Does it need the internet?

Not to catalog, search, or find duplicates. Everything stays on your machine.
